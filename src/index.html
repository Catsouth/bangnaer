❓ 使用说明

三步上手
1️⃣ 先有一张身份卡：你的邮箱、手机号、微信号，就是「身份」。
2️⃣ 用「设置 → 自动录入」把密码管理器/浏览器导出的文件喂进来，绑定关系自动识别，不用手打。
3️⃣ 之后想查「这个邮箱注册过啥」，点卡包里的卡，或者去关系图看星系。

常见问题
· 数据存在哪？只存这台设备 + 你自己填的 WebDAV，不经过任何第三方服务器，也不存你的密码（只记「用哪个账号登的」）。
· 换手机怎么恢复？旧手机开好 WebDAV 备份，新手机打开绑哪儿、填同一个 WebDAV，打开时会自动拉下来；或者旧机「导出 JSON 备份」，新机在设置里「导入备份恢复」。
· 导出的 JSON 是明文吗？是明文（含邮箱、手机号、账号名，不含密码），请存到安全的地方，别随手发给别人。
· 图标加载不出来？服务图标来自各官网的 favicon，需要联网；加载失败会显示首字母圆块，不影响使用。
· 屏幕锁 PIN 忘了？PIN 只存本机、我们看不到。忘了只能清除浏览器数据重来——数据会丢，所以开锁前请先导出一份备份。
